Switch GitHub accounts on Windows, in every tool at once

Work and personal GitHub accounts on one PC. One click moves the GitHub CLI, git, GitHub Desktop and VS Code to the other account, with no signing out and back in.

Pick an account. All four tools follow it.

Four tools, four separate sign-ins

The GitHub CLI, git, GitHub Desktop and VS Code each keep their own GitHub login, and none of them follows the others. Moving to another account usually means signing out and back in four times, and signing out deletes the saved token. The switcher signs every account in once and swaps the saved sign-ins when you switch.

GitHub CLICredential Manager gh:github.com:<user>gh auth switch

What it does

Shows where you are signed in
The active account, and which account each tool really uses, with mismatches flagged.
Switches in one click
Confirm once. A log shows every step the switcher took.
Never signs you out
Tokens are backed up and restored inside Windows Credential Manager. App sign-ins are moved aside, never deleted.
Stays on your PC
A localhost server with a key that changes every run. Tokens are never shown, logged or sent anywhere.
Closes apps the normal way
GitHub Desktop and VS Code close as if you closed them, so unsaved-work prompts still appear. Then they reopen.
Walks you through adding an account
Prepare the apps, sign in to each tool with live status, save. Progress survives a page refresh. Missed a tool? Sign in again and the profile is updated.

Quick start

You need:

  • Windows 10 or 11 with Windows PowerShell 5.1
  • Git for Windows with Git Credential Manager, and the GitHub CLI 2.40 or later
  • Python 3 on PATH for the VS Code part (standard library only)
  • Node.js 18 or later, only to build the page once

  1. Get the code

    git clone https://github.com/sale-shubham/github-account-switcher.git
cd github-account-switcher

  2. Build the page once

    cd web
npm install
npm run build
cd ..

  3. Start the switcher

    .\switch-github.ps1 -Ui

    Your browser opens the switcher. Keep the PowerShell window open while you use it.

  4. Add each account

    Click Add account and follow the four steps. Do it once per account. After that, switching is one click.

Prefer the command line?

.\switch-github.ps1                # show the current state and saved profiles
.\switch-github.ps1 work           # switch everything to the profile 'work'
.\switch-github.ps1 -Save work     # save what is signed in now as 'work'
.\switch-github.ps1 -Clear         # sign Desktop and VS Code out safely, to add an account

Questions

How do I use two GitHub accounts on one Windows PC?

Add each account once with Add account in the switcher (or -Save on the command line). After that, one Switch moves the GitHub CLI, git, GitHub Desktop and VS Code to the other account.

Does gh auth switch also change the account git pushes with?

Not with Git Credential Manager, the Git for Windows default. gh auth switch changes only the GitHub CLI. Git keeps pushing with the account saved in Git Credential Manager, and commits keep the old user.name and user.email. The switcher changes all three.

How do I switch GitHub accounts in GitHub Desktop or VS Code without signing out?

Signing out deletes the saved token, so you sign in from scratch every time. The switcher closes the app normally, swaps in the sign-in it saved for that account, and reopens it.

Is it safe? Where are my tokens?

Tokens stay in Windows Credential Manager, encrypted for your Windows user. The switcher runs on localhost only, with a key that changes every run, and never shows a token.

Does it work on macOS or Linux?

No. It is built on Windows Credential Manager and the Windows app data folders.

Does it handle SSH keys or GitHub Enterprise?

No. It covers HTTPS sign-ins on github.com. SSH keys and GitHub Enterprise Server hosts are not switched.
